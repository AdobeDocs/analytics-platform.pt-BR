# Exportação do Workspace

Este artigo descreve como as opções de exportação do Analysis Workspace podem ser usadas para implementar o seguinte [caso de uso de exportação de dados](overview.md):

- Relatórios ad hoc e recorrentes

## Introdução

A exportação de dados diretamente do Analysis Workspace permite que usuários individuais baixem ou enviem um projeto por email sem configurar um destino de nuvem ou pipeline de dados.

## Mais informações

Você pode baixar um projeto, ou parte de um projeto, do Analysis Workspace para a sua estação de trabalho como um arquivo PDF, CSV ou JSON. Os downloads são somente ad hoc e estão limitados a 50.000 linhas. Consulte [Baixar para sua estação de trabalho](/help/analysis-workspace/export/download-send.md) para obter mais informações.

Você também pode enviar um projeto por email para outros usuários em sua organização, seja ad hoc ou de acordo com um agendamento. Os relatórios enviados por email são limitados a 400 linhas. Consulte [Enviar para outros usuários](/help/analysis-workspace/export/t-schedule-report.md) para obter mais informações.

Para obter uma comparação de todos os métodos de exportação do Analysis Workspace, incluindo a exportação de tabelas completas para a nuvem, consulte [Visão geral da exportação](/help/analysis-workspace/export/export-project-overview.md).

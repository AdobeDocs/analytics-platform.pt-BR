# API de relatórios

Este artigo descreve como o [!DNL Customer Journey Analytics Reporting API] pode ser usado para implementar o seguinte [caso de uso de exportação de dados](overview.md):

- Integração personalizada de aplicativos

## Introdução

O [!DNL Customer Journey Analytics Reporting API] permite recuperar as mesmas dimensões e métricas processadas disponíveis no Analysis Workspace, de forma programática. Use o [!DNL Reporting API] para potencializar aplicativos personalizados, incorporar relatórios em ferramentas internas ou automatizar a recuperação de dados do Customer Journey Analytics sem exportar manualmente.

## Mais informações

O [!DNL Reporting API] usa o mesmo formato de solicitação e resposta que [!DNL Adobe Analytics] [!DNL Reporting API], mas usa um ponto de extremidade diferente. Se você estiver migrando integrações de relatórios do [!DNL Adobe Analytics], consulte o fluxo de trabalho de migração no [Guia de início rápido](/help/getting-started/cja-getting-started.md) para obter mais informações.

Para obter autenticação, pontos de extremidade disponíveis e limites de solicitação atuais, consulte a [documentação da API do Customer Journey Analytics](https://developer.adobe.com/cja-apis/docs/).
